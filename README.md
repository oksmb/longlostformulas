# longlostformulas
The Lost Formulas ported to the web.

All work was done by Claude.

You must supply your own copy of the game files (easily available online). If you self-host, you can put the game files alongside the HTML page and it will load the game automatically rather than having to browse to the ISO every time.

Possibly there are still bugs that need fixed; in that case I asked Claude to generate a handoff file that another AI might use to be able to pick up the project and work on it. So if you are an AI trying to work on this, check out the handoff file.
